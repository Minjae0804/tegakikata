# 테가키카타 — 사용법

일본어 한자를 필기로 연습하는 학습 게임. 서버 없이 내 구글 드라이브에만 데이터가 저장된다.

## 1. 처음 시작하기

1. 사이트 접속 → **드라이브 연결** 클릭 → 구글 로그인 팝업에서 계정 선택 및 접근 허용
2. 자동으로 드라이브에 `/TegakikataApp` 폴더와 기본 파일들이 만들어짐
3. **AI 프로바이더 선택**: Gemini 또는 Claude 중 하나를 고르고, 해당 API 키를 입력
   - Claude: [platform.claude.com](https://platform.claude.com)에서 발급
   - Gemini: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 발급
   - 어느 쪽이든 무료로 발급 가능. 예문 생성/채점에 이 키가 쓰인다.
4. **시작하기** 누르면 게임 모드 선택 화면으로 이동

다음에 다시 접속하면 "다시 연결하기" 버튼 하나만 누르면 이전 설정을 그대로 불러온다.

## 2. 빈칸 채우기 게임 (埋)

AI가 만든 일본어 예문의 빈칸을, 손으로 직접 써서 채우는 게임.

### 기본 흐름

1. 예문이 뜨고, 정답 부분이 빈칸(＿)으로 표시됨
2. **한자 입력** 또는 **히라가나 입력** 버튼으로 입력 방식 전환
3. 한 글자씩 써서(또는 눌러서) "입력한 글자" 칸에 순서대로 쌓기
4. 다 썼으면 **제출** → 정답 확인

### 한자 입력 (필기)

- 흰 칸에 손가락/마우스로 한자를 씀
- **인식하기** → 후보 한자 목록이 뜸 → 맞는 걸 선택하면 "입력한 글자"에 추가되고 캔버스가 비워짐
- **한 획 취소**: 마지막 획만 지움 / **지우기**: 전체 지움

### 히라가나 입력 (버튼)

- 휴대폰 자판처럼 자음 키(あ か さ ...)를 누르면 모음 5개(あいうえお)가 펼쳐짐 → 원하는 글자 선택
- **탁음(゛) / 반탁음(゜)** 버튼: 누르면 대기 상태가 되고, 바로 다음에 고르는 글자에 자동 적용됨 (예: 탁음 누르고 `か`행에서 `き` 선택 → `ぎ`가 입력됨)
- ゃゅょっ 같은 작은 글자는 따로 버튼으로 있음

### 여러 글자 단어

`勉強`처럼 두 글자 이상인 단어도, 한 글자씩 순서대로 입력해서 이어 쓰면 된다. 한자와 히라가나를 섞어 써야 하는 단어(`開ける` 등)도 입력 방식을 번갈아 전환하며 쓰면 된다.

### 잘못 썼을 때

"마지막 글자 지우기"로 방금 입력한 글자 하나만 되돌릴 수 있다. 제출 전까지는 자유롭게 수정 가능.

## 3. 문장 번역 게임 (訳)

AI가 낸 한국어 문장을 일본어로 번역하는 게임.

1. 한국어 문장이 뜸
2. 아래 입력창에 일본어로 번역해서 입력 (텍스트 입력, 필기 아님)
3. **채점하기** → AI가 의미/문법 기준으로 정답 여부와 피드백을 알려줌
   - 어순이나 표현이 정답과 달라도, 의미가 통하고 문법이 맞으면 정답 처리됨

## 4. 단어장 관리

기본적으로는 AI가 단어까지 알아서 골라 문제를 낸다. 직접 만든 단어장을 쓰고 싶으면:

### CSV 형식

```csv
kanji,reading,meaning,jlpt_level,notes
食,たべる,먹다,N5,
勉強,べんきょう,공부,N5,
```

- `kanji`, `reading`, `meaning` 필수 / `jlpt_level`, `notes` 선택
- 헤더 이름 기준으로 읽으므로 컬럼 순서는 상관없음
- 구글 시트나 엑셀에서 편집해도 됨

### 적용 방법

빈칸 채우기 게임 화면의 **"단어장 선택"** 버튼을 누르면:

- **폴더 탐색**: `wordbanks/` 안의 하위 폴더 → CSV 파일 순서로 찾아서 체크박스로 선택
- **내 드라이브에서 파일 선택**: 이미 갖고 있는 CSV 파일을 구글 피커로 직접 골라 가져오기 (직접 만든 파일은 이 방법으로 골라야 앱이 읽을 수 있음)
- **+ 새 단어장 만들기**: 앱 안에서 파일 이름과 CSV 내용을 바로 입력해 생성 (이렇게 만든 파일은 항상 접근 가능해서 가장 안정적)

원하는 파일을 체크하고 **"선택한 단어장 적용"**을 누르면 그때부터 그 단어들로 문제가 나온다. 화면 상단의 "단어 출처"에 지금 "드라이브"(내 단어장)인지 "AI 생성"인지 표시된다.

## 5. 문법 노트

드라이브의 `/TegakikataApp/grammar.md` 파일에 배운 문법 포인트를 자유 형식으로 적어두면, AI가 예문/문제를 만들 때 참고한다. 드라이브에서 직접 열어 수정하면 된다.

```markdown
## N5
- 〜てください: 부드러운 요청/지시
- 〜ましょう: 권유
```

## 6. 자주 묻는 것

**Q. 히라가나도 필기로 인식돼요?**
아니요, 필기 인식 라이브러리(kanjicanvas)는 한자만 지원한다. 히라가나는 버튼으로 입력해야 한다.

**Q. 계속 로그인해야 하나요?**
액세스 토큰은 브라우저를 새로고침하면 사라진다. 다시 "드라이브 다시 연결" 버튼만 누르면 된다.

**Q. 데이터는 어디에 저장되나요?**
전부 내 구글 드라이브(`/TegakikataApp` 폴더)에만 저장된다. 별도 서버는 없다.

**Q. API 사용료가 나오나요?**
Gemini/Claude 둘 다 무료 크레딧으로 시작할 수 있다. 이후 사용량이 많아지면 각 서비스의 요금 정책에 따라 과금될 수 있으니, 각 콘솔에서 사용량을 확인하는 게 좋다.
