# 테가키카타 — 사용법

## 1. 처음 시작하기

1. 사이트 접속 → **드라이브 연결** 클릭 → 구글 로그인 팝업에서 계정 선택 및 접근 허용
2. 자동으로 드라이브에 `/TegakikataApp` 폴더와 기본 파일들이 만들어짐
3. **AI 프로바이더 선택**: Gemini 또는 Claude 중 하나를 고르고, 해당 API 키를 입력
   - 키 발급 방법과 어느 쪽을 쓸지는 [AI API 키 발급](API_KEYS.md) 참고 — 지금은 **Claude를 권장**한다
   - 모델도 선택할 수 있다(비워두면 앱 기본 모델 사용)
4. **시작하기** 누르면 게임 모드 선택 화면으로 이동

다음에 다시 접속하면 "다시 연결하기" 버튼 하나만 누르면 이전 설정을 그대로 불러온다.

## 2. 게임 모드

### 빈칸 채우기 (埋)

AI가 만든 일본어 예문의 빈칸을, 손으로 직접 써서 채우는 게임.

**기본 흐름**

1. 예문이 뜨고, 정답 부분이 빈칸(＿)으로 표시됨
2. **한자 입력** 또는 **히라가나 입력** 버튼으로 입력 방식 전환
3. 한 글자씩 써서(또는 눌러서) "입력한 글자" 칸에 순서대로 쌓기
4. 다 썼으면 **제출** → 정답 확인

**한자 입력 (필기)**

- 흰 칸에 손가락/마우스로 한자를 씀
- **인식하기** → 후보 한자 목록이 뜸 → 맞는 걸 선택하면 "입력한 글자"에 추가되고 캔버스가 비워짐
- **한 획 취소**: 마지막 획만 지움 / **지우기**: 전체 지움

**히라가나 입력 (버튼)**

- 휴대폰 자판처럼 자음 키(あ か さ ...)를 누르면 모음 5개(あいうえお)가 오른쪽에 펼쳐짐 → 원하는 글자 선택
- **탁음(゛) / 반탁음(゜)** 버튼: 누르면 대기 상태가 되고, 바로 다음에 고르는 글자에 자동 적용됨 (예: 탁음 누르고 `か`행에서 `き` 선택 → `ぎ`가 입력됨)
- ゃゅょっ 같은 작은 글자는 따로 버튼으로 있음

**여러 글자 단어**

`勉強`처럼 두 글자 이상인 단어도, 한 글자씩 순서대로 입력해서 이어 쓰면 된다. 한자와 히라가나를 섞어 써야 하는 단어(`開ける` 등)도 입력 방식을 번갈아 전환하며 쓰면 된다.

단어장을 골라두면(4절) 그 단어들이 예문에 우선 쓰이고, 안 골라두면 AI가 알아서 단어까지 고른다.

### 문장 번역 (訳)

AI가 낸 한국어 문장을 일본어로 번역하는 게임.

1. 한국어 문장이 뜸
2. 아래 입력창에 일본어로 번역해서 입력 (텍스트 입력, 필기 아님)
3. **채점하기** → AI가 의미/문법 기준으로 정답 여부와 피드백을 알려줌 (어순이나 표현이 정답과 달라도, 의미가 통하고 문법이 맞으면 정답 처리됨)

### 단어장 맞추기 (単)

내가 고른 단어장(4절)에 있는 단어만으로 출제한다. AI가 임의로 단어를 지어내지 않는다. 두 방향을 상단 토글로 전환:

- **뜻·읽기 → 한자**: 뜻과 읽기를 보고 한자를 필기로 쓴다. AI 미사용 — 단어장 데이터와 글자 그대로 비교해서 채점.
- **한자 → 읽기·뜻**: 한자만 보고 읽기(히라가나)와 뜻(한국어)을 답한다. 오탈자나 동의어 표현까지 봐줘야 해서 AI로 채점한다.

### 단어장 학습 (習) — 플래시카드 + 복습 스케줄

정답을 맞히는 게임이 아니라, 한자를 보고 스스로 "안다/모른다"만 판단하는 자기평가 플래시카드다.

1. 카드에 한자만 보임 → 탭하면 읽기·뜻이 뒤집혀서 나옴
2. **모르겠어요** / **알아요** 중 골라서 답하면 다음 카드로 넘어감
3. 결과는 단어별로 드라이브(`saves/progress.json`)에 저장되고, 간격 반복(SRS) 방식으로 다음 복습 시점이 정해진다 — "알아요"가 쌓일수록 그 단어는 점점 뜸하게 나오고, "모르겠어요"를 고르면 바로 다음 세션에 다시 나온다
4. 오늘 복습할 게 없으면 "그래도 전체 단어 복습하기"로 기한과 상관없이 계속 볼 수 있다

빈칸 채우기·단어장 맞추기에서 단어장 단어를 풀 때도 같은 진도 기록에 결과가 반영된다(정답=안다, 오답=모른다로 취급). AI가 즉석에서 지어낸 단어는 기록되지 않는다.

## 3. 문법 노트

드라이브의 `/TegakikataApp/grammar.md` 파일에 배운 문법 포인트를 자유 형식으로 적어두면, AI가 예문/문제를 만들 때 참고한다. 드라이브에서 직접 열어 수정하면 된다.

```markdown
## N5
- 〜てください: 부드러운 요청/지시
- 〜ましょう: 권유
```

## 4. 단어장 관리

단어장 없이도 빈칸 채우기·문장 번역은 AI가 알아서 단어/문장을 골라 문제를 낸다. 다만 **단어장 맞추기**와 **단어장 학습**은 단어장이 있어야 동작한다.

### CSV 형식

```csv
kanji,reading,meaning,jlpt_level,notes
食,たべる,먹다,N5,
勉強,べんきょう,공부,N5,
```

- `reading`, `meaning` 필수 / `jlpt_level`, `notes` 선택
- `kanji`는 비워둬도 됨 — たくさん처럼 한자 표기가 없는 단어는 그렇게 등록하면, 각 게임이 알아서
  "한자 쓰기" 대신 "읽기 쓰기"로, "한자 보고 맞히기" 대신 "읽기 보고 뜻 맞히기"로 문제를 바꿔서 낸다
- 헤더 이름 기준으로 읽으므로 컬럼 순서는 상관없음
- 구글 시트나 엑셀에서 편집해도 됨
- 직접 만들기 번거로우면 [AI로 단어장 만들기](WORDBANK_AI_PROMPT.md)의 프롬프트로 교재 사진에서 바로 뽑아낼 수 있다

### 적용 방법

각 게임 화면의 **"단어장 선택"** 버튼을 누르면:

- **폴더 탐색**: `wordbanks/` 안의 하위 폴더 → CSV 파일 순서로 찾아서 체크박스로 선택
- **내 드라이브에서 파일 선택**: 이미 갖고 있는 CSV 파일을 구글 피커로 직접 골라 가져오기 (직접 만든 파일은 이 방법으로 골라야 앱이 읽을 수 있음)
- **+ 새 단어장 만들기**: 앱 안에서 파일 이름과 CSV 내용을 바로 입력해 생성 (이렇게 만든 파일은 항상 접근 가능해서 가장 안정적)

원하는 파일을 체크하고 **"선택한 단어장 적용"**을 누르면 그때부터 그 단어들로 문제가 나온다.

## 5. 자주 묻는 것

**Q. 히라가나도 필기로 인식돼요?**
아니요, 필기 인식 라이브러리(kanjicanvas)는 한자만 지원한다. 히라가나는 버튼으로 입력해야 한다.

**Q. 계속 로그인해야 하나요?**
액세스 토큰은 브라우저를 새로고침하면 사라진다. 다시 "드라이브 다시 연결" 버튼만 누르면 된다.

**Q. 데이터는 어디에 저장되나요?**
전부 내 구글 드라이브(`/TegakikataApp` 폴더)에만 저장된다. 별도 서버는 없다. 단어장 학습 진도는 `saves/progress.json`에 단어별로 쌓인다.

**Q. API 사용료가 나오나요?**
Gemini/Claude 둘 다 무료 크레딧으로 시작할 수 있다. 이후 사용량이 많아지면 각 서비스의 요금 정책에 따라 과금될 수 있으니, 각 콘솔에서 사용량을 확인하는 게 좋다.
