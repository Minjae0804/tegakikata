# 테가키카타 — 사용법

## 1. 처음 시작하기

1. 사이트 접속 → **드라이브 연결** 클릭 → 구글 로그인 팝업에서 계정 선택 및 접근 허용
2. 자동으로 드라이브에 `/TegakikataApp` 폴더와 기본 파일들이 만들어짐
3. **AI 프로바이더 선택**: Gemini 또는 Claude 중 하나를 고르고, 해당 API 키를 입력
   - 키 발급 방법과 어느 쪽을 쓸지는 [AI API 키 발급](API_KEYS.md) 참고 — 지금은 **Claude를 권장**한다
   - 모델도 선택할 수 있다(비워두면 앱 기본 모델 사용)
4. **시작하기** 누르면 게임 모드 선택 화면으로 이동

한 번 연결하면 새로고침하거나 다시 접속해도 자동으로 로그인 상태가 이어진다(화면에 아무것도 안 띄우고 조용히 재인증). 브라우저 세션이 끊겼거나(오래 로그아웃 상태였거나 등) 접근 권한을 철회한 경우에만 "다시 연결하기" 버튼이 뜬다.

### 모바일에 앱처럼 설치하기 (PWA)

브라우저 주소창의 "홈 화면에 추가" / "설치" 기능으로 앱처럼 설치할 수 있다. 아이콘으로 바로 실행되고 브라우저 주소창 없이 열린다.

- **Android(Chrome)**: 오른쪽 위 메뉴(⋮) → **홈 화면에 추가** (또는 주소창에 뜨는 설치 배너)
- **iOS(Safari)**: 하단 공유 버튼 → **홈 화면에 추가**
- **PC(Chrome/Edge)**: 주소창 오른쪽의 설치 아이콘 클릭

단, 설치해도 단어장/학습 진도 저장은 그대로 구글 드라이브를 쓰고 AI 채점은 그대로 인터넷 연결이 필요하다 — 설치는 "앱처럼 아이콘으로 바로 켜지는 것"이지 완전 오프라인 앱으로 만들어주는 건 아니다.

## 2. 게임 모드

### 빈칸 채우기 (埋)

AI가 만든 일본어 예문의 빈칸을, 손으로 직접 써서 채우는 게임.

**기본 흐름**

1. 예문이 뜨고, 정답 부분이 빈칸(＿)으로 표시됨
2. **한자 입력** 또는 **히라가나 입력** 버튼으로 입력 방식 전환
3. 한 글자씩 써서(또는 눌러서) "입력한 글자" 칸에 순서대로 쌓기
4. 다 썼으면 **제출** → 정답 확인

**한자 입력 (필기)**

- 흰 칸에 손가락/마우스로 한자를 씀
- **인식하기** → 후보 한자 목록이 뜸 → 맞는 걸 선택하면 "입력한 글자"에 추가되고 캔버스가 비워짐
- **한 획 취소**: 마지막 획만 지움 / **지우기**: 전체 지움

**히라가나 입력 (버튼)**

- 휴대폰 자판처럼 자음 키(あ か さ ...)를 누르면 모음 5개(あいうえお)가 오른쪽에 펼쳐짐 → 원하는 글자 선택
- **탁음(゛) / 반탁음(゜)** 버튼: 누르면 대기 상태가 되고, 바로 다음에 고르는 글자에 자동 적용됨 (예: 탁음 누르고 `か`행에서 `き` 선택 → `ぎ`가 입력됨)
- ゃゅょっ 같은 작은 글자는 따로 버튼으로 있음

**여러 글자 단어**

`勉強`처럼 두 글자 이상인 단어도, 한 글자씩 순서대로 입력해서 이어 쓰면 된다. 한자와 히라가나를 섞어 써야 하는 단어(`開ける` 등)도 입력 방식을 번갈아 전환하며 쓰면 된다.

단어장을 골라두면(4절) 그 단어들이 예문에 우선 쓰이고, 안 골라두면 AI가 알아서 단어까지 고른다.

### 문장 번역 (訳)

AI가 낸 문장을 반대 언어로 번역하는 게임. 화면 위쪽 **한국어 → 일본어** / **일본어 → 한국어** 버튼으로 방향을 바로 바꿀 수 있다(단어장 맞추기의 방향 토글과 같은 방식).

**한국어 → 일본어**
1. 한국어 문장이 뜸
2. 아래 입력창에 일본어로 번역해서 입력 (텍스트 입력, 필요하면 한자 필기/가나 입력기로 이어 쓰기도 가능)
3. **채점하기** → AI가 의미/문법 기준으로 정답 여부와 피드백을 알려줌 (어순이나 표현이 정답과 달라도, 의미가 통하고 문법이 맞으면 정답 처리됨)

**일본어 → 한국어**
1. 일본어 문장이 뜸
2. 아래 입력창에 한국어로 번역해서 입력
3. **채점하기** → AI가 의미 기준으로 정답 여부와 피드백을 알려줌 (어순/표현이 달라도 의미가 통하면 정답 처리됨)

### 단어장 맞추기 (単)

내가 고른 단어장(4절)에 있는 단어만으로 출제한다. AI가 임의로 단어를 지어내지 않는다(다만 아래 "AI 활용형 출제"를 켜면 그 단어의 활용형은 AI가 만든다). 두 방향은 언제든 자유롭게 전환할 수 있다:

- **뜻·읽기 → 한자**: 뜻과 읽기를 보고 한자를 필기로 쓴다. 기본은 AI 미사용 — 단어장 데이터와 글자 그대로 비교해서 채점.
- **한자 → 읽기·뜻**: 한자만 보고 읽기(히라가나)와 뜻(한국어)을 답한다. **AI 채점 사용** 토글로 전환 — 켜면 오탈자/동의어까지 봐주는 AI 채점, 끄면(또는 AI 설정이 없으면) 단어장과 정확히 일치해야 정답으로 처리하는 로컬 채점.

**답을 모르면**: 억지로 찍지 말고 **모르겠어요** 버튼을 누르면 오답과 동일하게 처리되고, 정답을 바로 보여준다. 정답 카드 아래에는 채점하지 않는 "✏️ 이 단어 손으로 써보기" 연습(접힌 상태로 시작)도 나온다.

**출제 순서**: 무작위가 아니라 복습이 급한 단어부터 우선 나온다(단어장 학습과 동일한 방식). 맞히면 그 방향 진도가 점점 늘어나서(뜸하게 나옴) 우선순위가 낮아지고, 틀리거나 "모르겠어요"를 누르면 다음 세션에서 최우선으로 다시 나온다.

**진도는 방향별로 따로 쌓인다**: "한자 쓰기" 실력과 "읽기·뜻 회상" 실력은 서로 다른 능력이라, 이 둘의 학습 진도를 분리해서 추적한다 — 한자를 잘 쓴다고 읽기·뜻까지 잘 안다는 보장이 없어서다.

**AI 활용형 출제** (옵션, AI 설정 필요): 켜면 사전형(食べる, 飲む 등) 그대로 내지 않고, AI가 자연스러운 활용형/파생형을 하나 만들어서(食べる→食べたい, 飲む→飲みすぎる 등) 그걸로 문제를 낸다 — 두 방향 모두에서 동작한다. 아래 "문법 노트 선택"으로 골라둔 문법 노트가 있으면 그 안의 문형을 우선 활용해서 만든다. 정답 공개 시 원형(사전형)과 어떤 문형을 썼는지도 같이 보여준다. 학습 진도는 활용형이 아니라 항상 원래 단어 기준으로 쌓인다. 매번 활용형만 나오면 사전형을 익힐 기회가 없으므로, 일정 확률로는 활용 없이 사전형 그대로도 낸다. "뜻·읽기 → 한자" 방향의 읽기 힌트는 활용형이 켜져 있어도 항상 사전형 읽기만 보여준다 — 활용된 읽기를 그대로 보여주면 활용 패턴 자체가 드러나서 정답을 알려주는 셈이라서다.

### 단어장 학습 (習) — 복습 우선순위 열람

이 페이지는 채점하지 않는다. 급한 단어부터 순서대로 보여주는 플래시카드 열람 도구다.

1. 카드에 한자(또는 한자가 없는 단어는 읽기)만 보임 → 탭하면 읽기·뜻이 뒤집혀서 나옴
2. 원하면 "✏️ 이 단어 손으로 써보기"로 채점 없는 필기 연습도 가능
3. **다음 단어**를 누르면 다음 카드로. "안다/모른다"를 스스로 고르지 않는다 — 그건 사용자 자기신고에 의존하는 방식이라, 실제 학습 진도는 여기서 갱신하지 않는다
4. 오늘 복습할 게 없으면 "그래도 전체 단어 복습하기"로 기한과 상관없이 계속 볼 수 있다

**진도(SRS)는 여기서 안 쌓인다.** 실제로 답을 맞히거나 틀렸을 때만(빈칸 채우기·단어장 맞추기·문장 번역에서) 단어별로 드라이브에 기록되고, 이 페이지는 그 기록을 읽어서 복습이 급한 순서로 카드를 보여주기만 한다. AI가 즉석에서 지어낸 단어(단어장에 없는 단어)는 기록되지 않는다. 진도는 단어장(CSV 파일) 단위로 따로 저장된다 — 자세한 건 아래 "4. 단어장 관리" 참고.

## 3. 문법 노트

`/TegakikataApp/grammar/` 폴더 — 단어장(wordbanks/)과 똑같은 구조다. 이 폴더 안에 배운 문법 포인트를 자유 형식으로 적은 `.md`(또는 `.txt`) 파일을 여러 개 만들어두고, 원하는 파일만 골라서 적용할 수 있다. 골라둔 내용은 AI가 예문/문제를 만들거나(빈칸 채우기·문장 번역) 단어장 맞추기의 "AI 활용형 출제"를 만들 때 참고한다.

- 각 게임 화면의 **"문법 노트 선택"** 버튼에서 하위 폴더 → 파일 순으로 탐색해 체크박스로 고르거나, **+ 새 문법 노트 만들기**로 앱 안에서 바로 쓰거나, 로컬 파일을 업로드할 수 있다(단어장 관리 방식과 동일)
- 어떤 화면에서 고르든 선택은 앱 전체에 공유된다(같은 캐시를 쓴다)
- 예전엔 `grammar.md` 파일 하나뿐이었다 — 그 파일을 계속 쓰고 싶으면 드라이브에서 `grammar/` 폴더 안으로 옮기기만 하면 된다(형식은 그대로 마크다운)

```markdown
## N5
- 〜てください: 부드러운 요청/지시
- 〜ましょう: 권유
- 〜すぎる: 너무 ~하다
```

## 4. 단어장 관리

단어장 없이도 빈칸 채우기·문장 번역은 AI가 알아서 단어/문장을 골라 문제를 낸다. 다만 **단어장 맞추기**와 **단어장 학습**은 단어장이 있어야 동작한다.

### CSV 형식

```csv
kanji,reading,meaning,jlpt_level,notes
食,たべる,먹다,N5,
勉強,べんきょう,공부,N5,
```

- `reading`, `meaning` 필수 / `jlpt_level`, `notes` 선택
- `kanji`는 비워둬도 됨 — たくさん처럼 한자 표기가 없는 단어는 그렇게 등록하면, 각 게임이 알아서
  "한자 쓰기" 대신 "읽기 쓰기"로, "한자 보고 맞히기" 대신 "읽기 보고 뜻 맞히기"로 문제를 바꿔서 낸다
- 헤더 이름 기준으로 읽으므로 컬럼 순서는 상관없음
- 구글 시트나 엑셀에서 편집해도 됨
- 직접 만들기 번거로우면 [AI로 단어장 만들기](WORDBANK_AI_PROMPT.md)의 프롬프트로 교재 사진에서 바로 뽑아낼 수 있다

### 적용 방법

각 게임 화면의 **"단어장 선택"** 버튼을 누르면:

- **폴더 탐색**: `wordbanks/` 안의 하위 폴더 → CSV 파일 순서로 찾아서 체크박스로 선택
- **내 드라이브에서 파일 선택**: 이미 갖고 있는 CSV 파일을 구글 피커로 직접 골라 가져오기 (직접 만든 파일은 이 방법으로 골라야 앱이 읽을 수 있음)
- **+ 새 단어장 만들기**: 앱 안에서 파일 이름과 CSV 내용을 바로 입력해 생성 (이렇게 만든 파일은 항상 접근 가능해서 가장 안정적)

원하는 파일을 체크하고 **"선택한 단어장 적용"**을 누르면 그때부터 그 단어들로 문제가 나온다.

### 학습 진도는 단어장 CSV 안에 같이 저장됨

단어장(CSV 파일) 하나가 어휘 목록이자 세이브 파일이다 — 별도 진도 파일이 없다. 앱이 CSV에 진도 컬럼 12개를 자동으로 붙여서 관리한다:

```csv
kanji,reading,meaning,jlpt_level,notes,kanji_e,kanji_iv,kanji_r,kanji_la,kanji_l,kanji_n,reading_e,reading_iv,reading_r,reading_la,reading_l,reading_n
食,たべる,먹다,N5,,2.5,1440,3,0,2026-08-15T09:00:00.000Z,2026-08-16T09:00:00.000Z,2.5,10,1,0,2026-08-14T08:00:00.000Z,2026-08-15T08:00:00.000Z
```

- `kanji_*`는 "한자 쓰기" 진도, `reading_*`는 "읽기·뜻 회상" 진도 — 서로 다른 실력이라 따로 저장된다
- `e/iv/r/la/l/n` = 이지팩터/간격(분)/복습횟수/실수횟수/마지막 복습 시각/다음 복습 시각. 한 번도 안 푼 스킬은 전부 빈 칸
- 이 컬럼들은 앱이 자동으로 채우고 갱신한다 — 직접 손댈 필요는 없다(다만 손대도 형식만 지키면 무방)
- 서로 다른 단어장에 같은 단어(같은 한자+읽기)가 있어도 진도는 섞이지 않는다 — "N5 1과"에서 食べる를 다 외웠어도 "회화 표현집"의 食べる는 처음 보는 것처럼 새로 학습한다
- 진도가 갱신되면 그 단어장 CSV 전체를 다시 써서 저장한다(1분마다 자동 저장 + 화면 이동 시). 그 사이 시트에서 직접 단어를 고치거나 추가/삭제했다면 어휘 쪽은 항상 최신(원격) 내용을 그대로 두고 진도만 얹는다

> **예전에 `saves/progress-<단어장 이름>.json` 파일로 진도를 저장하던 시절의 데이터가 남아있다면**, 그 단어장을 다음에 다시 열 때 앱이 자동으로 한 번 읽어서 CSV 진도 컬럼에 병합해준다 — 따로 옮길 필요 없다. 그 옛날 파일 자체는 이후로 안 쓰이니 지워도 그만이다.

## 5. 자주 묻는 것

**Q. 히라가나도 필기로 인식돼요?**
아니요, 필기 인식 라이브러리(kanjicanvas)는 한자만 지원한다. 히라가나는 버튼으로 입력해야 한다.

**Q. 계속 로그인해야 하나요?**
아니요. 새로고침해도 자동으로 로그인 상태가 이어진다(화면 뒤에서 조용히 재인증). 브라우저 세션이 끊겼거나 권한을 철회한 경우에만 "다시 연결" 버튼이 뜬다.

**Q. 데이터는 어디에 저장되나요?**
전부 내 구글 드라이브(`/TegakikataApp` 폴더)에만 저장된다. 별도 서버는 없다. 단어장 학습 진도는 별도 파일이 아니라 그 단어장 CSV 파일 자체에 진도 컬럼으로 같이 쌓인다("4. 단어장 관리" 참고).

**Q. API 사용료가 나오나요?**
Gemini/Claude 둘 다 무료 크레딧으로 시작할 수 있다. 이후 사용량이 많아지면 각 서비스의 요금 정책에 따라 과금될 수 있으니, 각 콘솔에서 사용량을 확인하는 게 좋다.
