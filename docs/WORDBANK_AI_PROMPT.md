# AI로 단어장 만들기

교재 페이지 사진이나 단어 목록 파일을 ChatGPT/Claude/Gemini 같은 AI 챗봇에 올리고 아래 프롬프트를 붙여넣으면, 테가키카타 CSV 형식에 맞는 단어장을 바로 뽑아준다.

## 사용법

1. 교재 페이지 사진(여러 장 가능) 또는 단어 목록이 담긴 파일(PDF/텍스트/스프레드시트/이미지)을 준비한다
2. 원하는 AI 챗봇에 파일/사진을 첨부하고, 아래 프롬프트를 그대로 붙여넣는다
3. 결과로 나온 CSV를 `.csv` 파일로 저장한다
4. 테가키카타의 게임 화면 → **단어장 선택** → **CSV 파일 업로드**에 그 파일을 올린다 — 형식을 확인한 뒤 자동으로 드라이브 `wordbanks/` 폴더에 저장된다 (형식이 잘못됐으면 업로드 전에 알려준다)
   - 붙여넣기가 더 편하면 **+ 새 단어장 만들기**에 CSV 내용을 직접 붙여넣어도 된다

## 프롬프트

아래 내용을 그대로 복사해서 쓰면 된다.

```text
첨부한 자료(사진/파일)에서 일본어 단어를 모두 추출해서, 아래 CSV 형식에 맞춰 출력해줘.

형식: kanji,reading,meaning,jlpt_level,notes
- kanji: 한자 표기. 한자가 없는 단어(순수 히라가나/가타카나 단어 등)는 그 표기를 그대로 씀
- reading: 히라가나 읽기 전체
- meaning: 한국어 뜻. 간결하게, 콤마 없이
- jlpt_level: 확실히 알 때만 N5/N4/N3/N2/N1 중 하나, 모르면 비워둠
- notes: 예문이나 헷갈리는 포인트가 있으면 짧게 한 줄, 없으면 비워둠

규칙:
- 첫 줄은 반드시 헤더 그대로: kanji,reading,meaning,jlpt_level,notes
- 값 안에 콤마나 줄바꿈이 들어가면 큰따옴표로 감싸기
- 같은 단어가 중복되면 하나로 합치기
- 원문에 없는 단어를 임의로 추가하지 말 것 — 자료에 실제로 나온 단어만
- 다른 설명 없이, 마크다운 코드블록(```) 안에 CSV 내용만 출력할 것
```

## 결과 예시

```csv
kanji,reading,meaning,jlpt_level,notes
食べる,たべる,먹다,N5,
勉強,べんきょう,공부,N5,
```

## 참고

- 업로드 시 검증하는 것은 형식(필수 컬럼 `kanji`/`reading`/`meaning`, 유효한 행이 하나 이상 존재하는지)뿐이다. 한자·읽기·뜻이 실제로 맞는지는 AI도 완벽하지 않으니, 특히 읽기(활용형 등)는 한 번 훑어보고 쓰는 걸 권장한다
- CSV 형식 자체는 [사용법 문서](GUIDE.md#4-단어장-관리) 참고
